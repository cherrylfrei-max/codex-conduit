# codex-conduit
Codex Conduit — Multi-account routing, automatic failover, quota monitoring, and a local gateway for Codex CLI and Codex App.

*(Formerly known as Codex Switcher / Seamless Switch)*

Codex Conduit is a desktop multi-account routing and automatic failover gateway for Codex CLI, Codex App, and supported IDE integrations.
